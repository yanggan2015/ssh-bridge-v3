# 阶梯架构图（S0 – S13）

每张图节点集合完全相同，**只有颜色变化**，所以把相邻两张并排看，橙色就是这一步新增的东西。

图是**分层带**：一个色块 = 一个模块，按 ui / core / services / 外部 四层排列；层内不画连线（连线与数据流见 `docs\架构总览.md` 的数据面图与 `docs\详细设计.md` 各步接口），这样相邻两张只差颜色，最容易对比。

| 颜色 | 含义 |
|---|---|
| 灰蓝实线 | 外部设备 / 客户端（一直存在） |
| 绿色实线 | 已完成（≤ 当前步） |
| 橙色粗线 | **本步新增** |
| 灰色虚线 | 未实现，后续步骤预留的挂点 |

## 两层结构：先做完整终端工具，再挂扩展

S1–S7 造出 `desktop.exe` 本体——一个原生 Win32 的完整终端工具（通道 / 终端 / 文件 / 按钮 / 托盘 / 日志），S7 结束时可以独立交付，且不监听任何端口。S8–S13 是挂在这个工具上的扩展，每项独立开关；全关掉，本体照常工作。

| 层 | 步骤 | 内容 |
|---|---|---|
| — | S0 | 工程地基 |
| 本体 | S1 | 配置 / 环形日志 / 串口桥 |
| 本体 | S2 | SSH 出站链路 |
| 本体 | S3 | 窗口壳 + 生命周期 |
| 本体 | S4 | 终端窗格 |
| 本体 | S5 | 通道管理 + 热应用 |
| 本体 | S6 | 界面偏好 / 会话操作 / 快捷键 |
| 本体 | S7 | 文件与脚本（本体出口） |
| 扩展 | S8 | SSH 入站网关 |
| 扩展 | S9 | HTTP 基元 + 网页端 |
| 扩展 | S10 | Agent 接口 |
