# 网页控制台十维验收标准（Web 化）

> 适用对象：`ssh-bridge v3` 的 18081 网页控制台（`/dashboard` 及其余 11 页）。
> 桌面 Win32 窗口的 D1–D10 见 `docs/窗口验收标准.md`；本文件只把其中依赖 Win32 控件的条目替换为浏览器/DOM/HTTP 等价物，评分门槛不变：**10 维每维 0–10 分，全部 ≥9 才算通过；任一维 <9 必须重新设计该维并重跑全量验收**。

## 一、评分规则

- 每维必须同时具备：量化数字（`output/ux-audit/*.json`）、截图（`output/ux-audit/*.png`）、可复现命令与“点了什么→看到什么”的记录。
- 脚本全绿只是必要条件，不是充分条件；终评还要人工看桌面与移动截图，确认不遮挡、不裁剪、不别扭。
- 测试环境：18081 + token `web-audit-2026`；桌面 1440×960，移动 390×844；浏览器 Edge headless。
- 正式结果落盘：`output/acceptance/web-ten-dim-2026-11-23/score.json`。

## 二、10 个维度与 9 分门槛

### D1 功能正确性

- 12 个页面全部可打开；终端、通道、分屏、板控、快捷/脚本、继电器、TFTP/NFS/共享、TCP 转发、隧道、Agent、配置的控件逐个执行。
- **9 分**：控件清单 100% 执行过；每个动作有可观察结果；无 404/400/504/崩溃/静默失败。
- **10 分**：同一功能“按钮/快捷键/接口”三条路径结果一致，且写操作后可读回业务真值。

### D2 用户操作便利性

- **9 分**：刷新/清屏/分屏/查找聚焦等常用动作 ≤1 次点击；至少 4 个快捷键（F5、Ctrl+F、F3、Ctrl+Shift+B）；Tab 顺序能到达终端输入；移动端有可见菜单/令牌入口；无“必须猜”的入口。
- **10 分**：查找框回车即下一个命中；所有常用按钮有 title/占位提示；快捷键有统一帮助入口。

### D3 布局合理性（终端优先）

- 原则：终端是主角，导航与工具只能在必要带宽内。
- **9 分**：桌面 `.terminal-shell` 面积 ≥ 视口 65%；移动端 ≥65%；控件不重叠、页面不横向/纵向出界；终端工具带高度 ≤ 视口 12%；导航可一键收起。
- **10 分**：全屏终端；导航收起状态可记忆；窗口尺寸变化后自动 fit。

### D4 视觉美观与一致性

- **9 分**：全站可见文本字号 ≥13px；无文字裁剪；同类按钮尺寸/间距一致；对齐成行成列；配色克制；无闪烁/残影；toast 不遮挡主要操作区。
- **10 分**：在线/离线/锁定状态有颜色区分；终端等宽字体；桌面与移动保持同一视觉语言。

### D5 响应与流畅

- **9 分**：100 次状态请求 p95 ≤80ms、max ≤500ms；输入→回显 p95 ≤300ms，其中本地回环端点 p95 ≤50ms；连续 300 次混合请求 0 失败；空闲 CPU ≤3%；**RX 计数可见**。
- **10 分**：重连/清缓冲等慢操作有进行中态且不冻结界面。

### D6 状态反馈与可感知

- **9 分**：变更动作有回执（toast/状态行/列表变化/日志）；查找显示命中数；复制/粘贴有提示；失败有明确文案，不是静默。
- **10 分**：耗时操作有进度，可取消。

### D7 稳定性与资源

- **9 分**：300 次混合动作 + 3 次导航显隐 + 3 次窗口尺寸变化后进程与 xterm 存活；句柄增长 ≤30；GDI 增长 ≤30；单实例第二进程不抢占；WS 断线重连可控；退出后无残留端口。
- **10 分**：连续 30 分钟内存增长 ≤10MB。

### D8 容错与边界

- **9 分**：非法 JSON、未知画框、未知 API、超大文本、重复狂点、断线重连、第二实例、DPI 150% 八类场景全部可控，有错误码或提示，不崩不卡死。
- **10 分**：错误文案给出下一步建议。

### D9 可测试性与可观测性

- **9 分**：DOM id 唯一稳定；`/api/help` 有操作清单；`/status` 有业务真值（channels/panes/services）；`/logs` 可查；无模态阻塞；页面无 JS 错误/5xx。
- **10 分**：状态带版本/时间戳，便于断言。

### D10 一致性与可维护性

- **9 分**：同一功能同一代码路径；导航 12 项且当前页唯一高亮；按钮文案无空/undefined/null/NaN；文档（README、详细设计、验收报告）与实现一致；评分证据与最终二进制 SHA 对得上。
- **10 分**：新增控件/页面只改一处注册表即可被导航与测试发现。

## 三、执行顺序

1. `mingw32-make -C C:\code\ssh-bridge-windows3 -j8`，要求 0 warning / 0 error。
2. 起 18081（运行目录 `output/terminal-test`），恢复测试配置，记录 exe SHA-256。
3. 跑 `output/webtest/run-full-suite.ps1`（17 套件）。
4. 跑 `output/webtest/web-ui-score-check.js`（35 项 Web 量化 + 桌面/移动截图）。
5. 跑 `output/webtest/web-ten-dim-extra.js`（空闲 CPU、RX、17MB、狂点、DPI150）。
6. 另测 300 次资源增长与第二实例。
7. 填 `score.json` 与 `docs/网页控制台十维验收报告.md`；任一维 <9 回设计重来。
