## 四、回显延时（越低越好）

| 通道 | 实测 |
| --- | --- |
| loop1 串口回环 | 17–19 ms |
| s6loop2 串口回环 | 17 ms |
| ssh-link-demo1 / demo2 | 66 ms |

测量口径：从 `term.input` 发出，到 `term.search` 命中回显（含本地 HTTP 往返，约 10–15ms 固定开销），因此程序内部写环与回显路径更快。
真实 COM3(1.5M)/COM5(115200) 已 open 到 ready，但当前板端静默、无回显字节，故不计入延时；接入会回显的固件后按同一口径复测即可。
