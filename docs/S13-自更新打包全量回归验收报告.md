## 4. 本次修复

1. `scripts\package.ps1` 无 BOM，Windows PowerShell 5.1 把中文和部分变量解析坏，`Join-Path` 得到空路径；补 UTF-8 BOM，并把 `utf8NoBOM` 改为 .NET UTF-8 无 BOM 写入，`powershell -File` 与 `pwsh -File` 均可打包。
2. `scripts\dist-config.json` 的 `ui.pane_channels` 原为空，包内首次启动默认落到离线 SSH 示例，终端冒烟 `term.search` 失败；改为默认 `["loop1"]`，包内启动即落在可用回环通道。
3. `web_console.cpp` 多处 JS/CSS/HTML 单行超过 200 字符，S0 代码整理失败；拆行后 `quality_gate` 全 PASS，10 页功能和移动布局复测通过。
4. `tests\step1_check.ps1` 原先把用户目录配置带进“无监听端口”断言，S8 合法监听 2222 时误报；改为 `output\step1\run` 隔离空配置启动。
5. 启动时 `Shell` 初始化末尾无条件调用 `save_layout_state()`，每次打开应用都会按当前配置模型重写用户配置文件；删除该调用，并增加 `layout_user_input_` 门控，只有用户实际点击/按键/菜单操作后才允许保存布局。
6. `tests\step1_check.ps1` 增加 G-8：隔离配置每次重置为 `{}` 并记录 SHA-256，启动后断言哈希不变；本次 19 项 ALL PASS，证明启动路径不再写配置。`ui_bridge_check` 41 项同时 ALL PASS，UI 桥动作仍可正常写布局。
