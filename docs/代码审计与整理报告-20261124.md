## 4. 未作为本轮缺陷的事项

### 产品功能缺口

`C6/C9/D4/D5/D6/F1/F3/F4/G5/H6/L7/N5` 共 12 项未实现，`A10/L6/M8` 3 项部分实现。它们属于 `docs/功能清单.md` 与全功能报告已登记的产品范围，不是代码质量缺陷，本轮不伪装成“已修复”。

### 外部依赖

- `ok3568` COM5 115200 仍报 `Retry 0: Got TIMEOUT` / `Retry 4: Got 03 sector header`，串口可打开不等于板端 shell 可用。
- 真实继电器、NFS 跨机 `mount`、EADK 板侧 `scp-pull/scp-push` 仍需对应硬件、镜像、sshd 与密钥。
- 以上不能用编译通过或假桥测试替代真实硬件结论。

### 静态审计边界

本轮未接入 ASan/UBSan，不做“内存安全已闭环”的过度声明；NFS 的 Linux 分支只完成源码审计与 Windows 侧编译验证，未在 Linux 主机实跑 `mount --bind` / `umount`。这是下一轮可用独立 Linux 环境补的验证项。
