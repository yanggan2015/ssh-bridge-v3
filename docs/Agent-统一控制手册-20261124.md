# Agent 统一控制手册与 `/agent-help` 页面（2026-11-24）

## 1. 目标

把 18081 的 Agent 入口从“设备面仪表盘”改成**可直接投喂给 Agent 的纯文档页**：

- 一个链接拿到全部接口、全部功能域、四类通道控制方法；
- 页面只做文字、表格、代码块，不做指标卡、锁列表、18096 状态卡；
- 与网页按钮共用同一批 18081 handler，不另起一套 Agent 后端；
- 兼容旧链接，并保留原仪表盘作为 `/agent-status` 诊断入口。

参考旧仓 `C:\code\ssh-bridge` 的 `/agent-help`：全局 Markdown 手册 + 单通道手册 + `?format=md` 原文 + 浏览器渲染。

## 2. 路由

| 路由 | 行为 |
|---|---|
| `/agent-help` | 全局控制手册，浏览器渲染为 HTML |
| `/agent-help?format=md` | 同一内容 Markdown 原文 |
| `/agent-help/<channel>` | 单通道手册，curl 已填通道名 |
| `/agent-help/<channel>?format=md` | 单通道 Markdown 原文 |
| `/agent`、`/help`、`/docs` | 与 `/agent-help` 同内容 |
| `/agent-status` | 原 Agent 仪表盘（指标卡、通道 scan、锁、18096 状态），仅诊断 |
| `/api/help` | 机器契约，仍为 74 项 operations |

## 3. 全局手册内容

1. 入口与边界：Base、原文、兼容别名、单通道、`/api/help`、鉴权、18096 只诊断。
2. 先读 6 条：发现顺序、`channel/board/link` 路由、先锁后写、三种命令语义、按钮 id 规则。
3. 设备地图：通道、板控按钮/继电器、快捷指令、文件/TFTP、NFS/共享、TCP 转发、分屏、作业、通道配置、人工专用。
4. 当前通道表：由运行中的 `AppCore::entries()` 生成，含类型、状态、设备/目标、单通道链接。
5. 最短闭环：health → `/api/help` → scan → probe → lock → command_block → log → unlock。
6. 终端/日志/作业：`/command_block`、`/command`、`/agent/exec`、`/write`、`/send_keys`、`/log`、`/jobs`。
7. 四类通道：serial / ssh / powershell / telnet 的能做什么、不能做什么。
8. 按钮/继电器/快捷指令：只使用当前配置 `enable=true` 的 id。
9. 文件/服务/分屏/配置：`/api/files`、`/tftp/*`、NFS、共享、TCP 转发、`/api/panes`、通道 CRUD、reload/reconnect。
10. 全量接口目录：与 `kOperations` 同源自动生成，分组列出 74 项，方法/路径/鉴权/参数/返回/说明。
11. 错误与安全：401、423、404、400、202+job、5xx 与红线。

## 4. 单通道手册

每个通道页包含：

- 通道类型、状态、设备/目标、鉴权；
- 能力表：命令/日志、原始写/按键、串口控制、上下电/重启、U-Boot、文件、锁；
- 填好通道名的最短闭环 curl；
- 只列 `enable=true` 的按钮，按 `id` 去重；`enable=false` 只报数量，不给可执行 curl；
- 类型专属段：
  - 串口：`/serial/open|close|break|lines|configure`、U-Boot 提示；
  - SSH：远端 shell 边界、`/reconnect`、禁止擅自重启；
  - PowerShell：本机命令边界、`/reconnect`、禁止模拟硬件；
  - Telnet：远端 shell、`/reconnect`、禁止擅自重启。

这修复了旧 `/help/ok3568` 的两个问题：

- `power_on`、`power_off`、`reboot` 各输出两遍；
- `enable=false` 的 `power_on` 仍给出可执行 curl。

## 5. 页面渲染

`help_page_html()` 不再用深色 `<pre>` 包裹原文，改为轻量 Markdown → HTML：

- 白底、最大宽度 920px、无 JS；
- 标题、表格、代码块、列表、行内 code/bold；
- 表格逐格渲染，`<channel>` 转义后原样显示；
- 顶部导航：Agent 手册 / 通道 / 运行状态 / `/api/help` / Markdown 原文。

## 7. 边界

- 18081 仍是唯一 Agent 板控面；18096 只做桌面窗口自检，不进板控闭环。
- Tunnel、自升级、全局配置/密钥、入站 SSH、UDP 发现列为“人工专用”，不提供 Agent 写接口。
- `/agent-status` 保留原仪表盘，仅供人诊断；Agent 不应从它取板控接口。
