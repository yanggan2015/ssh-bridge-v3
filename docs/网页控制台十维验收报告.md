## 二、低于 9 分的发现与修复

### 1. D2/D5 从底部直通条改为桌面同款原位输入（核心改造）

- 依据：桌面 `src/ui/terminal/view.cpp` 没有 Edit 控件，`WM_CHAR` 把可打印字符逐字 `send_active()`，光标直接画在终端网格；`WM_KEYDOWN` 处理方向/Home/End/Tab/Backspace 等，Enter 走 `line_ending_bytes()`。
- 首次修复（build29）只做到字符不囤整行，仍保留底部 `#cmd` 捕获条；用户要求与桌面完全一致后，整段删除。
- 本轮改造（build30）：
  - 删除 `.terminal-input`、`#cmd`/`#send`/`#clear` 的 HTML、CSS 与 JS，网页不再有独立输入框；
  - xterm host 占满 `.terminal-shell` 剩余高度，桌面实测 xterm 底边距 shell 底边 **1px**；
  - `focusTerm()` 统一聚焦 xterm 隐藏 textarea；加载 120ms 自动聚焦、切通道 80ms 再聚焦；移动端点击输出区才弹软键盘；
  - `attachCustomKeyEventHandler` 按桌面字节接管方向/Tab/Backspace/Home/End/Enter；普通字符走 `queueXtermData()`，每键立即进入 8ms 有序合批，`IN_CHAIN` 串行保序；
  - Enter 按 `/status` 的通道 `kind` + `line_ending` 计算：SSH `lf` 发 `\n`，否则 `\r`；串口 `cr`/`lf`/`none`/默认 `\r\n`；
  - 移动端 16 键条仅 `max-width:720px` 显示，桌面 `display:none`；它是辅助键，不是输入框。
- 复测：loop-chars 输入 `AB` 未按 Enter，`TX +2`、`RX +2`、终端同区出现 `AB`、光标 `x=2`；Enter 在 CRLF 通道 `TX +2` 并换行。
- 真 SSH：左键后插入 `X` 得 `CXD`；右键 `+1`；Home/End、Backspace 删除、Ctrl+U、Tab 补全 `echo`、↑ 调出 `printf` 历史、↓ 清空，全部通过。

### 2. D5 回显 p95 曾 53ms，超过本地回环 50ms 门槛

- 修复：Web 线程 `mg_mgr_poll(mgr, 10)` 收紧到 **5ms**（`src/services/web/web_console.cpp`）。
- 复测：原位输入 10 字符回显 p50 **32ms**、p95 **33ms**、max **33ms**；API 100 次 p50 1.3ms、p95 1.7ms；30 秒负载下 15 次探针 p50 102ms、p95 120ms；空闲 CPU 1.23%，低于 3%。

### 3. D5 RX 计数在移动端不可见

- 新增 `#rxBadge`（桌面）与 `#rxBar`（移动终端带），`updateRxBadge()` 同时刷新；桌面与移动都能看到 `RX nB`。

### 4. D4 toast 遮挡页头/通道下拉

- toast 改到右侧垂直居中，移动端 46% 高度；量化截图前清理瞬时浮层。页头、通道下拉、工具带、底部输入均无遮挡。

### 5. D10 文档落后于实现

- README 旧的 138×28/42×22/12px 已改为 66.3%/69.6%/41×38/13px；详细设计 9.1 改为“无独立输入框、xterm 原位输入”；本报告与 `score.json` 绑定 build30 SHA。

## 三、同框与桌面同款原位输入专项（27/27）

证据：`output/ux-audit/web-same-box-stream-check.json`、`output/ux-audit/run-same-box-desktop-input7.log`、`output/ux-audit/web-same-box-stream.png`。

### 1. 几何：没有输入框，输出区就是输入区

| 元素 | x / y / 宽 / 高 | 结论 |

| `.terminal-shell` | 23 / 223.7 / 1394 / 657.5 | 会话框，底边 881.14 |

输出区从会话框顶部一直铺到底部；输入就在 xterm 当前光标处，不另占一行。

### 2. 流式下发与回显（loop-chars）

- 输入 `A`、`B`，不按 Enter：`TX +2`、`RX +2`，同一 xterm 出现 `AB`，光标 `x=2`。
- 左方向键：光标 `2→1`；右方向键：`1→2`；Tab：`2→8`；Backspace 有下发且状态行提示“退格”；Enter：CRLF 通道 `TX +2`、光标 `x=0` 并换行；下/上方向键 `y` 正确加减。
- 状态行回执示例：`已写入 loop-chars · 键盘`、`已写入 loop-chars · 退格`。
- 页面无 JS 错误；加载后 `activeElement` 为 `xterm-helper-textarea`。

### 3. 真 SSH shell 的编辑键

- 输入 `CD`，左移一位插入 `X`，行内容变为 `CXD`；右移一位光标 `+1`。
- Home/End：光标 `29 → 32`；Backspace：`32 → 31`（字符被远端 shell 删除）。
- Ctrl+U：`31 → 29`，输入行清空。
- Tab：输入 `ech` 后补全出 `echo `。
- ↑：调出历史 `printf "AB"`；↓：回到空命令行。

### 4. 移动端与桌面差异

- 移动端 390×844：shell 364×629.1，xterm 362×596.1，底部 16 键条 362×31 位于壳内，`display:flex`；桌面同一套页面键条隐藏。
- 移动端仍无独立输入框；点击输出区后直接键入 `MOBILE_DIRECT_OK`，同区回显成功。
