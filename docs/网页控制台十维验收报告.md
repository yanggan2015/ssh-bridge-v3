## 二、低于 9 分的发现与修复

### 1. D2/D5 底部输入不是流式直通（核心修复）

- 现象：`#cmd` 把字符先囤在本地，按 Enter 才整行 `/write`；输入 “AB” 时 `TX` 不变，方向键只移动本地输入框光标，设备完全收不到。
- 根因：旧 `sendTermText()` 只在 Enter 触发发送；方向键、Backspace 未映射为终端序列。
- 修复：底部输入改为**串口式直通**：
  - 可打印键：每个字符进入 8ms 合批队列，立即经 `/write` 下发，不再本地囤整行；
  - 方向键：`ESC[A/B/C/D`；Home/End：`ESC[H/F`；PgUp/PgDn：`ESC[5~/6~`；Delete：`ESC[3~`；
  - Tab `\t`、Backspace `\x7f`、Enter `\r`、Esc `\x1b`、Ctrl+C/D/Z/L/U/R 原始控制码；
  - 输入法走 `input/composition`，粘贴走 `paste`，移动端走 `beforeinput`；
  - 输入条本身不显示重复字符，避免“底部一份 + 上方回显一份”的双写；字符与光标只在上方同一个终端里流式出现。
- 复测：loop 通道输入 `AB` 未按 Enter，`TX 17→19`、`RX 17→19`、终端出现 `AB`、光标 `x=2`。
- 真 SSH：左键后插入 `X` 得到 `CXD`；右键 `+1`；Home/End、Backspace 删除、Ctrl+U、Tab 补全 `echo`、↑ 调出 `printf` 历史、↓ 清空，全部通过。

### 2. D5 回显 p95 曾 53ms，超过本地回环 50ms 门槛

- 修复：Web 线程 `mg_mgr_poll(mgr, 10)` 收紧到 **5ms**（`src/services/web/web_console.cpp`）。
- 复测：最终 p50 **34ms**、p95 **36ms**、max **36ms**；空闲 CPU 1.23%，低于 3%。

### 3. D5 RX 计数在移动端不可见

- 新增 `#rxBadge`（桌面）与 `#rxBar`（移动终端带），`updateRxBadge()` 同时刷新；桌面与移动都能看到 `RX nB`。

### 4. D4 toast 遮挡页头/通道下拉

- toast 改到右侧垂直居中，移动端 46% 高度；量化截图前清理瞬时浮层。页头、通道下拉、工具带、底部输入均无遮挡。

### 5. D10 文档落后于实现

- README 旧的 138×28/42×22/12px 已改为 66.3%/69.6%/41×35/13px；详细设计新增 `9.1 终端优先网页仪表盘`；本报告与 `score.json` 绑定最终 SHA。

证据：`output/ux-audit/web-same-box-stream-check.json`、`output/ux-audit/run-same-box-stream3.log`、`output/ux-audit/web-same-box-stream.png`。

|---|---|---|

输出在上、键条居中、输入在下；输入没有独立窗口、独立日志区或独立 WS。

### 2. 流式下发与回显（loop-chars）

- 输入 `A`、`B` 两个字符，不按 Enter：`TX` 立即 `17→19`，`RX` 立即 `17→19`。
- 同一 `.terminal-shell` 上方出现 `AB`，xterm 光标 `x=2`，底部输入框不囤积字符。
- 左方向键：光标 `2→1`；右方向键：`1→2`；Tab：`2→8`；Enter：`x=0` 且 `TX+1`；下方向键 `y+1`；上方向键 `y-1`。
- 每次按键状态行都有回执，例如 `已写入 loop-chars · 输入`、`已写入 loop-chars · 退格`。

### 3. 真 SSH shell 的编辑键

- 输入 `CD`，左移一位插入 `X`，行内容变为 `CXD`；右移一位光标 `+1`。
- Home/End：光标 `29 → 32`；Backspace：`32 → 31`（字符被远端 shell 删除）。
- Ctrl+U：`31 → 29`，输入行清空。
- Tab：输入 `ech` 后补全出 `echo `。
- ↑：调出历史 `printf "AB"`；↓：回到空命令行。
