# 功能清单（v3 重建基线）

**来源**：`C:\code\ssh-bridge` 的 `DESIGN.md`、`docs/设计文档.md`、`需求列表.md`，以及 v2 已实现代码（`src/*`、`desktop/*`、`webui_static/*`）。

**形态前提**（本轮确认，优先于旧文档）：`desktop.exe` 是一个**完整的原生 Win32 终端工具**——串口/SSH 通道、终端渲染、SFTP、按钮、托盘都在这个进程里，界面直读内存。**其余能力（入站 SSH、网页、Agent、TFTP/NFS、转发/隧道）都是挂在这个工具上的扩展**，每项可独立开关，关掉不影响本体。

**图例**
- 类别：**本体** = 没有它就不是完整终端工具；**扩展** = 可选插件。
- 来源：`rN` = `需求列表.md` 第 N 条；`D§x` = `DESIGN.md` 第 x 节；`X§x` = `docs/设计文档.md` 第 x 节。
- 步骤：见 `docs/详细设计.md` 对应小节（S0–S13 与本节条目一一对应）；总览见 `docs/架构总览.md`。
