## 2. 方法与证据口径

- 桌面：经 UI 桥读取控件树与真实窗口句柄，使用 `CB_SHOWDROPDOWN` 展开每个 ComboBox，逐 index 选择并回读选中文本；同时截取父窗口与弹出列表的并集。截图进程设置 `SetProcessDpiAwarenessContext(-4)`，坐标为物理像素。
- Web：Playwright + Edge，逐页枚举 `<select>` 与 datalist 关联输入；对每个 option 执行 `selectOption` 或逐项聚焦/输入，回读当前值，再恢复原值；每个控件、每种编辑器状态截图。
- 判定标准：控件存在、可展开、候选可读、切换后值能回读、无 409/JS 异常、截图无越界或遮挡主操作。
- 截图中的输入值可能是“遍历到最后一项”的临时状态；凡涉及保存的对话框均点“取消”，未写入配置。

### 4.2 Web 修复

1. **通道编辑器补齐常用候选**：设备 13 项（COM1–10 + `loop:ai/demo/chars`）、波特率 10 项（9600–3000000）、编码 2 项、SSH 端口 5 项、TERM 5 项、Keepalive 5 项、列 5 项、行 5 项、超时 5 项、PowerShell 程序 3 项。
2. **继电器编辑器补齐候选**：端口 COM1–10、通道数 1/2/4/8、波特率 9600–115200、写后延时 20–500。
3. **板控 relay 参数补齐候选**：每条间隔、继电器通道 1–8、脉冲/保持秒 0.5/1/2/5。
4. **服务页补齐候选**：TFTP 端口 69/6969/1069、绑定 IP 0.0.0.0/127.0.0.1、NFS 别名 `/share`、`/mnt/share`、UID/GID 0/1000/1001、共享端口 18082/18083/8080。
5. **数字字段改为 `type="text" inputmode="numeric"`**（`aHold` 用 `decimal`）：保留自由输入，同时让 datalist 的候选箭头在聚焦时可出现；若保留 `type=number`，Edge 不显示 datalist 指示器。
