- 终端区：xterm 原位输入，无独立输入框；字符 8ms 合批后 `/write`，桌面/移动端同一输入模型。
- 终端工具箱：查找并定位下一处、复制、A−/A+ 字号、全屏切换、清空缓冲、清屏、日志下载。
- 画框区：只读展示 `/api/panes` 的画框数与各画框通道，可切换原生激活画框。
- WS 断线提示与退避重连；CDN 不可用时退化为 ANSI 净化 `<pre>` 只读回显。

### 2. 通道管理 `/channels`

- 通道列表：名称、类型、运行态、串口/SSH/PowerShell/Telnet 参数。
- 新增串口、SSH、PowerShell、Telnet 四类通道编辑器；表单联动。
- 编辑、改名、删除；名称必填与重名校验；删除后清理画框引用。
- 保存后走配置落盘 + 手术式热应用，其他通道 ring 不重建。
- 刷新列表、Bearer token 保存；错误输入返回明确中文提示。

### 3. 板控动作 `/actions`

- 按通道筛选板控按钮；显示真实 id、label、backend、enabled、requires_lock。
- 新增/编辑/删除按钮；commands 型与 script（Lua）型。
- 互斥规则：同 id 不能两个 backend 同时 enable；冲突有明确错误。
- 按钮测试、启停与保存；危险动作在 Agent 帮助中单独标注。

### 4. 快捷/脚本 `/button-script`

- 按通道维护快捷指令：label + command，点击即向该通道发送并回车。
- 新增/编辑/删除快捷指令；每个画框通道独立一套。
- 内嵌 Lua / DSL 速查，和 `docs/脚本参考-S12.md` 对齐。
- 空状态提供“新增第一条”入口。

### 5. 继电器 `/relay`

- 继电器设备 CRUD：名称、串口、波特率、脉宽等参数。
- 设备列表、刷新、新增设备。
- 通道绑定/测试入口；设备不可达时返回明确 400 业务错误。
- 与桌面“继电器与板控按钮”面板共用配置。

### 6. TFTP `/tftp`

- 配置卡：启停、根目录、端口、绑定 IP、允许写入；非法值校验。
- 运行状态卡：运行/端口/根目录/可写；启动、停止、刷新。
- 共享文件卡：浏览目录、进入子目录、共享根、打开、新建目录、上传、下载、删除。
- 文件路径做根目录越界拒绝；上传支持多部分表单。

### 7. NFS `/nfs`

- 配置卡：启停、根目录、别名 `/share`、UID、GID。
- 运行状态卡：运行状态与端口；启动、停止、刷新。
- 共享文件卡：目录浏览、新建目录、上传、下载、删除。
- 与桌面文件服务面板共用 NFS 配置。

### 8. 共享目录 `/share`

- HTTP 共享配置：启停、端口（默认 18082）、根目录。
- 运行状态卡：URL、运行态；启动、停止、刷新。
- 文件浏览/上传/下载/新建目录/删除；支持 `/tools/`、`/skills/` 分发。
- “打开”直接打开共享根浏览页。

### 9. TCP 转发 `/tcp-forward`

- 配置：启停、监听 IP、端口基数、目标端口、板网 CIDR。
- 启动/停止/保存配置；运行状态展示监听数、活动连接、字节数、错误。
- 本机 `port_base+末字节` 转发到板 `:22`；有效 listen fd 做 poll。
- 配置热重载切换目标端口有测试覆盖。

### 10. 隧道 `/tunnel`

- 配置：启停、隧道 exe、服务器地址/端口、token。
- HTTP 映射与 SSH 映射分别开关；本地/远端端口可自动选口。
- 启动/停止/保存；状态卡显示 PID、端口、重启次数、错误。
- 健康检查与进程被杀后的自动重启。

### 11. Agent 接口 `/agent`

- 18081 设备控制面状态：服务、版本、构建、鉴权、API 开关。
- 通道与终端态表：5 通道、类型、运行态、终端探测、Agent 锁、按钮数、工件数。
- 租约锁卡：当前锁、TTL、session、人工接管提示。
- 18096 桌面 UI 桥状态只读展示；明确“18081 不代理 18096”的边界。
- 接口速查：发现、巡检、锁、命令、日志、作业、TFTP 工件的 curl 顺序。

### 12. 配置 `/config`

- “基础 / 详细”两个 Tab；字段搜索框；读取配置、保存并重载。
- 表单化编辑 14 个配置域：default、boards、ssh、powershell、telnet、inbound_ssh、web、agent、tftp、share、nfs、tcp_forward、tunnel、discovery、relay_devices、ui/window。
- 不要求用户直接改 JSON；保存后 UI 线程重载。
- 未知键保留、四类通道数组往返、窗口配置拆分均有专项测试。
